# Drowsiness AI Detection System

## About the Project
Drowsiness AI is a driver-monitoring project designed to detect signs of driver fatigue using computer vision and machine learning.

The project is currently under development.

## Features
- Eye detection and eye-landmark analysis
- Face detection and facial-landmark processing
- Drowsiness prediction using machine-learning models
- Dataset collection, training, and validation scripts
- Driver-monitoring dashboard components

*Feature availability and accuracy depend on the current implementation and testing.*

## Technologies Used
- Python
- Computer Vision
- Machine Learning
- OpenCV (if used in the current implementation)
- Pandas and NumPy (if used in the current implementation)

## Project Structure
The repository contains Python scripts for detection, feature analysis, model training, prediction, validation, and dashboard functionality, along with datasets and trained model files.

## Current Status
**In progress.** Features, model performance, and integration are still being developed and tested.

## How to Run
1. Clone or download this repository.
2. Create and activate a Python virtual environment.
3. Install the dependencies required by the project.
4. Run the appropriate application entry point after configuring the required files and dependencies.

A `requirements.txt` file and detailed setup instructions will be added as the project develops.
